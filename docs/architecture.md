# MMmaker 架构文档

## 系统概述

MMmaker 是一套完整的数学建模竞赛自动化系统，通过多智能体协作完成从问题分析到论文撰写的全流程，目标产出达到国奖水平的竞赛论文。

## 智能体角色

### 1. CoordinatorAgent（协调者）
- **职责**：识别用户意图，拆解数学建模问题
- **输入**：用户输入的完整题目
- **输出**：结构化的问题列表（JSON 格式）
- **关键能力**：非建模问题拒绝、JSON 解析重试

### 2. ModelerAgent（建模手）
- **职责**：分析问题类型，制定建模方案
- **输入**：结构化问题列表
- **输出**：每个问题的建模方案（模型选择、求解思路、验证策略、可视化方案）
- **关键能力**：模型选择决策树、物理可行性约束、可视化方案设计

### 3. CoderAgent（代码手）
- **职责**：生成并执行 Python 代码
- **输入**：建模方案 + 子任务描述
- **输出**：代码执行结果 + 生成的图片
- **关键能力**：代码沙盒执行、错误反思重试、学术绘图规范

### 4. WriterAgent（写作手）
- **职责**：撰写学术论文
- **输入**：代码执行结果 + 图片 + 模板配置
- **输出**：论文章节内容
- **关键能力**：段落式写作、文献引用、图片插入

### 5. ReviewerAgent（评审手）
- **职责**：质量评审和反馈
- **输入**：建模方案 / 代码结果 / 论文内容
- **输出**：评分 + 反馈 + 改进建议
- **关键能力**：多维评分、建设性反馈、国奖标准

## 工作流

### 完整流程

1. **问题拆解**：CoordinatorAgent 拆解问题 → HIL 检查点
2. **建模设计**：ModelerAgent 设计方案 → HIL 检查点 → ReviewerAgent 评审
3. **环境初始化**：创建代码沙盒、文献检索器
4. **求解阶段**（循环）：
   - CoderAgent 生成执行代码
   - ReviewerAgent 评审代码结果
   - WriterAgent 撰写对应章节
   - ReviewerAgent 评审论文章节
5. **写作阶段**：WriterAgent 撰写封面、摘要等
6. **最终评审**：ReviewerAgent 评审完整论文 → HIL 检查点
7. **保存结果**：生成 res.md 和 res.json

### HIL 人机协作

关键节点暂停等待用户审批，支持 6 种决策动作：
- `confirm`：确认继续
- `edit`：编辑后继续
- `regenerate`：重新生成
- `ask`：提问澄清
- `skip`：跳过当前步骤
- `abort`：中止任务

### 质量反馈循环

```
Agent 输出 → ReviewerAgent 评审 → 评分低于阈值？
                                    ↓ 是
                              反馈注入 → 重新生成
```

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Vue 3 + TypeScript + Vite + Pinia |
| 后端 | FastAPI + Python 3.12 |
| LLM | LiteLLM 风格封装（OpenAI / Anthropic） |
| 代码执行 | Jupyter Kernel（本地）/ E2B（云端） |
| 消息 | Redis Pub/Sub + WebSocket |
| 文献 | OpenAlex API |
