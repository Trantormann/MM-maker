# MMmaker 国奖级质量标准

本文档定义了 MMmaker 系统为保证生成国奖级论文所遵循的核心质量标准。

## 建模质量规范

### 模型选择决策树

| 问题类型 | 特征 | 推荐模型 |
|---------|------|---------|
| 预测类 | 预测未来数值 | ARIMA / XGBoost / GM(1,1) / LSTM |
| 评价决策类 | 评价/排序/选方案 | AHP / TOPSIS / 熵权法 |
| 分类聚类类 | 分类/分群 | 随机森林 / SVM / K-means |
| 优化类 | 求最大/最小 | 线性规划 / 遗传算法 / NSGA-II |
| 统计分析类 | 变量关系 | 相关性分析 / 方差分析 / SHAP |
| 仿真类 | 系统演化 | 蒙特卡洛 / 元胞自动机 |

### 物理可行性约束

工程优化问题必须考虑物理可行性：
- 每个优化变量必须有物理上界和下界
- 优化结果不能违反物理限制
- 明确写出无约束解和约束解的区别

### 参数定量依据

所有模型参数必须有明确来源（三选一）：
1. 数据统计
2. 文献引用
3. 校准实验

## 写作质量规范

### 段落式写作

- 严格禁止分点式论述出现在正文
- 使用流畅的论文级段落语言
- 使用过渡连接词保证逻辑连贯

### 图表分析规范

- 每张图片配 3 行以上分析解读
- 说明图表展示了什么、关键发现、对结论的支撑
- 图表必须有编号和描述

### 模型选择论证

- 说明为什么选择该模型
- 与备选方案对比
- 因果与相关严格区分

## 评审标准

### 评分维度（0-10 分）

| 维度 | 权重 | 评分要点 |
|------|------|---------|
| 摘要质量 | 高 | 完整概述问题、方法、结果、结论 |
| 模型合理性 | 高 | 假设有依据、参数有来源 |
| 结果可信度 | 高 | 误差分析、交叉验证 |
| 写作规范性 | 中 | 段落式写作、图表分析充分 |
| 创新性 | 中 | 模型适配性、方法创新 |
| 完整性 | 中 | 结构完整、逻辑清晰 |

### 评分等级

| 分数 | 等级 | 说明 |
|------|------|------|
| 9-10 | 优秀 | 国奖水平 |
| 7-8 | 良好 | 省奖水平 |
| 5-6 | 一般 | 需要改进 |
| 3-4 | 较差 | 需要大幅修改 |
| 0-2 | 差 | 需要重做 |

## 常见扣分项

1. 模型选择无理由或理由不充分
2. 参数无来源说明
3. 图表无分析解读
4. 分点式写作
5. 因果与相关混淆
6. 敏感性分析缺失或不充分
7. 假设无合理性说明
8. 结果无误差分析
9. 物理可行性约束缺失
10. 数据泄露（时序特征使用未来信息）
